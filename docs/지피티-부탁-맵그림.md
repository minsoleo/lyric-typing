# 지피티에게 부탁할 맵 그림 (2026-11-20)

캐릭터를 만든 지피티 대화에서 이어서 부탁하면 그림체가 비슷하게 나와요.
한 번에 하나씩 보내고, 받은 그림을 저에게 붙여 주세요.

---

## 🏯 깃발쟁 — 동양풍 맵

### 먼저 보낼 말 (그림체 맞추기)
```
앞에서 만든 캐릭터들과 같은 그림체로 게임 맵 그림을 부탁할게. 위에서 비스듬히 내려다보는 탑뷰(3/4 시점) 2D 게임 아트, 굵은 외곽선, 밝고 선명한 색. 분위기는 안개 낀 산속의 동양 사원·궁궐이야: 진한 회색 기와와 금색 테두리, 붉은 기둥, 회색 돌바닥, 회색 바위 절벽, 분홍·주황 꽃나무. 지금부터 하나씩 부탁할게.
```

### ① 풀밭 타일 → `east-ground`
```
게임 바닥에 깔 풀밭 타일 1장. 정사각형 1024x1024, 위에서 똑바로 내려다본 모습. 안개 낀 산속 느낌의 차분한 푸른빛 이끼 풀밭에 아주 작은 돌과 분홍 꽃잎이 드문드문. 여러 장을 가로세로로 이어 붙여도 이음새가 안 보이게(seamless). 그림자·테두리·글씨 없이 바닥 무늬만.
```

### ② 돌길 타일 → `east-path`
```
게임 길에 깔 돌바닥 타일 1장. 정사각형 1024x1024, 위에서 똑바로 내려다본 모습. 동양 사원 마당의 회색 네모 돌바닥에 가는 주황색 줄무늬. 이어 붙여도 이음새가 안 보이게(seamless). 그림자·테두리·글씨 없이.
```

### ③ 나무 3 + 바위 기둥 3 → `east-props`
```
흰 배경 한 장(1536x1024)에 게임 물건 6개를 2줄로 따로따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선.
윗줄: 분홍 꽃나무, 주황 단풍나무, 동양 소나무 (둥그런 나무 꼭대기가 보이게).
아랫줄: 회색 바위 기둥 3개 — 납작한 것, 크고 높은 것, 중간 것 (사진 속 산 절벽처럼 층층이 깎인 회색 바위).
물건끼리 겹치지 않게 넉넉히 띄우고, 바닥 그림자는 아주 연하게. 배경은 완전한 흰색.
```

### ④ 연못 + 붉은 다리 → `east-pond`
```
흰 배경(1536x1024)에 동양 정원 연못 하나. 탑뷰 3/4 시점, 굵은 외곽선. 가로로 긴 타원 연못에 연꽃잎과 비단잉어 몇 마리, 연못 가장자리는 회색 돌. 연못 가운데를 가로지르는 붉은 아치 다리(금색 장식). 연못 하나만 크게, 배경은 완전한 흰색.
```

### ⑤ 작은 장식 9개 → `east-decor`
```
흰 배경 한 장(1536x1536)에 작은 바닥 장식 9개를 3x3 칸으로 따로따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선, 작고 낮은 물건.
1줄: 푸른빛 풀 덤불 A, 풀 덤불 B, 낮고 납작한 관목
2줄: 분홍 꽃잎 더미, 노란 국화 몇 송이, 하늘색 도라지꽃 몇 송이
3줄: 작은 석등, 이끼 낀 작은 돌, 둥글게 다듬은 회양목
서로 겹치지 않게 넉넉히 띄우고, 배경은 완전한 흰색.
```

### ⑥ 붉은 깃발 + 돌 제단 → `east-flag`
```
흰 배경(1536x1024)에 2개를 왼쪽·오른쪽에 따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선.
왼쪽: 깃대에 달린 세로로 긴 동양풍 붉은 깃발(진한 빨강 바탕, 금색 테두리와 금색 무늬, 끝에 술 장식). 깃대 끝에 금색 장식. 바람에 살짝 나부끼는 모습.
오른쪽: 깃발을 꽂아 둘 둥근 돌 제단(바닥에 납작한 원형 돌 받침, 가장자리에 금색·붉은 무늬). 위에서 본 둥근 모양.
배경은 완전한 흰색.
```

## 🏰 점령전 — 성 맵

### 먼저 보낼 말
```
이번엔 같은 그림체로 중세 성 맵 그림을 부탁할게. 탑뷰(3/4 시점) 2D 게임 아트, 굵은 외곽선. 회색 돌로 지은 성, 성벽 위는 울퉁불퉁한 성가퀴, 횃불과 깃발이 있는 분위기. 하나씩 부탁할게.
```

### ① 돌바닥 타일 → `castle-floor`
```
성 안마당 돌바닥 타일 1장. 정사각형 1024x1024, 위에서 똑바로 내려다본 모습. 크기가 조금씩 다른 회색 돌판, 틈에 약간의 이끼. 이어 붙여도 이음새가 안 보이게(seamless). 그림자·테두리·글씨 없이 바닥 무늬만.
```

### ② 성벽 면 띠 → `castle-wall`
```
게임에서 높은 곳의 낭떠러지 앞면으로 쓸 성벽 그림 1장. 가로로 긴 1536x512. 살짝 위에서 내려다본 회색 돌벽의 앞면이고, 맨 위 가장자리에 돌 테두리. 가로로 여러 장 이어 붙여도 이음새가 안 보이게(좌우 seamless). 벽 면만 화면 가득, 배경·글씨 없이.
```

### ③ 계단 2개 → `castle-stairs`
```
흰 배경(1536x1024)에 돌계단 2개를 왼쪽·오른쪽에 따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선, 회색 돌.
왼쪽: 화면 위쪽(멀리)으로 올라가는 넓은 돌계단.
오른쪽: 화면 오른쪽으로 올라가는 넓은 돌계단.
계단 양옆에 낮은 돌 난간. 배경은 완전한 흰색.
```

### ④ 장애물 6개 → `castle-props`
```
흰 배경 한 장(1536x1024)에 성 안 물건 6개를 3x2 칸으로 따로따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선.
윗줄: 둥근 돌 망루 기둥, 갑옷 기사 석상, 쌓인 나무 상자
아랫줄: 나무 술통 몇 개, 횃불이 타는 돌 화로, 창과 방패를 꽂아 둔 무기 거치대
서로 겹치지 않게 넉넉히 띄우고, 배경은 완전한 흰색.
```

### ⑤ 팀 깃발 + 성문 → `castle-banners`
```
흰 배경 한 장(1536x1024)에 3개를 가로로 따로 띄워서 그려 줘. 탑뷰 3/4 시점, 굵은 외곽선.
1: 성벽에 거는 세로로 긴 빨간 깃발(금색 테두리), 2: 같은 모양의 파란 깃발(은색 테두리), 3: 나무 문짝과 쇠창살이 있는 회색 돌 성문(아치형).
배경은 완전한 흰색.
```
