# 숲속의 한바탕 — 캐릭터와 스킬 정리

숲속에서 한바탕 싸우는 2D 타자 대결 게임. (예전 이름: 주문 대결, 주소는 그대로 `magic.html`)
민솔님이 정한 스킬 내용(`문서\타자게임 캐릭터.txt`)을 바탕으로 이름을 짓고 설명을 다듬음.
게임 속 실제 숫자는 `magic-spells.js`에 있고, 숫자는 해 보면서 바꾸면 됨.
2026-11-18: 민솔님 피드백으로 전체 수정 (아래 표가 수정한 값).

## 규칙

- 스킬 이름 = **키보드로 치는 주문**. 기본 스킬은 2~5글자, 궁극기는 12글자 이상 긴 문장.
- 스킬 + Enter → 장전(5초) → 오른쪽 클릭으로 발사. 장전은 한 번에 하나.
  - 예외: **그림자 은신**은 Enter만 쳐도 바로 쓰이고, 다른 스킬을 장전한 채로도 쓸 수 있음.
- 평타는 오른쪽 클릭 (장전한 게 없을 때). 이름을 칠 필요 없음.
- **스킬을 쓰는 동안은 다른 스킬을 치거나 장전할 수 없음** (그림자 은신만 예외). 평타와 이동은 됨.
  - 쓰는 동안 = 스킬의 지속 시간 (예: 칼끝의 맹세 6초, 검의 폭풍 3초, 바위벽 5초, 성역 10초). 돌진은 달리는 동안, 칼바람은 휘두르는 1.5초.
  - 바로 끝나는 공격(강철 사슬, 목 긋기, 빛의 창, 숲속의 섬광)은 막는 시간 없음.
  - 스킬 막대: 쓰는 중인 칸은 흰 테두리 + ⏳ 남은 시간, 나머지 칸은 🔒. 캐릭터 둘레에 흰 고리가 줄어듦.
- **궁극기 게이지**: 가만히 있어도 천천히 차고, 싸우면 더 빨리 참. 가득 차면 긴 이름을 쳐서 장전 → 오른쪽 클릭. 쓰면 0으로.
  - 1초마다 1 / 스킬로 준 피해 1 → 0.5 / 평타로 준 피해 1 → 0.3 / 회복 1 → 0.3 / 받은 피해 1 → 0.2 / 스킬 이름을 맞게 칠 때마다 → 3 (100이면 가득)
- **연습판 ♾ 무제한** (기본으로 켜짐): 대기 시간과 궁극기 게이지 없이 마음껏 써 볼 수 있음. 아래 버튼을 눌러 "⏳ 실전처럼"으로 바꾸면 실제 대결처럼 대기 시간·게이지가 생김.
- "가리킨 적" = 마우스로 가리킨 적. 아군에게 거는 스킬은 연습판에서는 나에게 걸림.
- 피해 감소가 걸려 있을 때 맞으면 숫자가 **파란색 + 🛡** 로 떠서 줄어든 게 보임 (예: 7 → `-4 🛡`).

| 말 | 뜻 |
|---|---|
| 근접 | 바로 앞에 붙어야 맞는 공격 |
| 리치 | 공격이 닿는 거리 |
| 기절 | 잠깐 아무것도 못 하는 상태 (스턴) |
| 나약함 | 주는 피해가 줄어드는 상태 |

## 🛡 가데온 (Gadeon) — 탱커 · 강철 수호자

> 아군을 지키며 맨 앞에서 싸워요. 체력 160, 가장 느림.
> 디자인: **한 손엔 검, 한 손엔 방패**를 든 갑옷 기사

| 칸 | 이름 (치는 주문) | 하는 일 | 대기 |
|---|---|---|---|
| 평타 | **강철 베기** | 바로 앞 적을 검으로 벰 (근접, 피해 10, 리치 120) | 0.9초 |
| 1 | **바위벽** | 마우스 쪽에 바위벽을 **5초** 동안 세움. 적이 쏜 공격이 막히고, **아무도 지나갈 수 없음** (돌진·끌려오기도 막힘) | 10초 |
| 2 | **수호의 방패** | 가장 가까운 아군이 **8초** 동안 받는 피해 40% 감소 | 12초 |
| 3 | **강철 사슬** | 사슬을 **빠르게** 던져 맞은 적을 내 앞으로 끌어온 뒤 피해 10 | 9초 |
| 4 | **파쇄 돌격** | 마우스 쪽으로 **멀리**(460) 돌진, 멈춘 자리에서 폭발해 주변 적에게 피해 20 | 8초 |
| 5 | **검의 폭풍** | 3초 동안 앞쪽으로 검 연타 (0.25초마다 피해 5, 리치 110) | 14초 |
| 궁 | **꺾이지 않는 강철 군단의 함성** | 8초 동안 나와 주변 아군: 받는 피해 **−50%**, **공격 리치 +50%**, 공격력 +30%, 속도 +25%, 평타 피해 2배 | 게이지 |

## 🗡 레이브 (Rave) — 딜러 · 그림자 칼잡이

> 피해를 가장 많이 주지만 몸이 약해요. 체력 100.
> 디자인: **양손에 단검**을 든 날쌘 전사

| 칸 | 이름 (치는 주문) | 하는 일 | 대기 |
|---|---|---|---|
| 평타 | 단검 베기 | 앞을 짧고 아주 빠르게 벰 (근접, 피해 9, 리치 72) | 0.25초 |
| 1 | **칼바람** | **1.5초 동안** 앞쪽을 3번 휘두르고(한 번에 피해 8, 모두 맞으면 24) 뒤로 훌쩍 물러남 | 6초 |
| 2 | **질풍 베기** | 마우스 쪽으로 **멀리**(520) 달려가며 지나간 적 **모두 똑같이** 피해 22 | 8초 |
| 3 | **목 긋기** | **화면 안에 보이는** 가리킨 적의 등 뒤로 순간 이동해서 피해 22 (거리 상관없음) | 10초 |
| 4 | **그림자 은신** | **15초** 동안 **완전히 투명**(걸을 때 발자국 먼지만 보임) + **속도 2배**. 공격하거나 스킬을 쓰면 풀림. ★ Enter만 쳐도 바로, 장전 중에도 가능 | 16초 |
| 5 | **칼끝의 맹세** | 6초 동안 나와 주변 아군 공격력 **+40%** | 14초 |
| 궁 | **멈춰 버린 세계를 가르는 칼날** | **쓴 자리(내 위치)를 중심으로** 넓은 범위(650)가 **12초 동안 남음**. 범위 안에 들어온 적은 절반 속도로 느려짐(나가도 1초 동안은 느림). 그동안 나는 속도 +30%, 피해 +40% | 게이지 |

## 👫 친구랑 연습 (온라인, 2026-11-18)

- 캐릭터 고르기 화면 위쪽 **"👫 친구랑 연습"** → 닉네임 → **🏠 방 만들기** (숫자 4자리 방 코드가 나옴) → 친구는 코드를 넣고 **들어가기**.
- 한 방에 최대 8명. 허수아비 3개도 같이 있음 (허수아비 모드를 누가 바꾸든 방 전체가 같이 바뀜).
- **빨강 팀 / 파랑 팀**: 처음엔 방장 빨강, 들어온 친구 파랑. 위쪽 "팀 ⇄" 버튼으로 언제든 바꿀 수 있음.
  - **다른 팀 = 적**: 공격이 맞고, 기절·끌어당기기·느려짐·나약함도 걸림.
  - **같은 팀 = 아군**: 공격이 안 아프고, 회복과 강화가 걸림.
- 아군에게 거는 스킬
  - 가장 가까운 아군 한 명 (600 안, 없으면 나): 수호의 방패, 수호의 축복
  - 나 + 주변 아군 (350 안): 칼끝의 맹세, 꺾이지 않는 강철 군단의 함성
  - 아군 모두: 질주 회복 / 우리 팀 샘·성역 안에 있으면 회복 / 덩굴 화살이 아군에 맞으면 회복 5
- 다른 팀이 그림자 은신을 쓰면 거의 안 보임 (같은 팀은 반투명으로 보임). 다른 팀 바위벽은 내 공격을 막음.
- 위쪽에 방 코드와 사람 목록(👑 = 방장), 화면 오른쪽 위에 "누가 누구를 쓰러뜨렸는지"가 뜸.
- 계산 방법: 각자 자기 캐릭터를 계산해서 0.1초마다 보냄. 맞힌 사람이 "맞았어요" 신호를 보내면 맞은 사람이 자기 피해 감소를 계산. 허수아비는 방장 컴퓨터가 계산 (방장이 나가면 다음 사람이 이어받음).
- 판 뒤집기와 같은 Firebase 사용 (`rooms/<4자리>`, `game: 'magic'`). 마지막 사람이 나가면 방이 지워짐.

## ⚔ 대결 모드 (2026-11-19)

- 친구랑 연습 방에서 **방장(👑)** 만 시작할 수 있음. 위쪽 줄에서 시간(2분 / 3분 / 5분) 고르고 **⚔ 대결 시작**.
- 빨강·파랑 팀에 한 명 이상씩 있어야 시작됨.
- **3·2·1 준비** (못 움직임) → 시작! → 정해진 시간 동안 **상대 팀을 많이 쓰러뜨린 팀이 이김**. 쓰러지면 3초 뒤 우리 팀 출발 자리에서 다시 일어남.
- 대결 중에는
  - 허수아비가 사라짐
  - ♾ 무제한이 꺼짐 → 실제 대기 시간·궁극기 게이지 (게이지는 0부터)
  - 팀 바꾸기, 허수아비 모드 버튼은 잠김
- 맵 위 가운데에 **빨강 점수 · 남은 시간 · 파랑 점수**. 마지막 10초는 시간이 빨갛게 바뀜.
- 끝나면 **결과 화면**: 이긴 팀, 점수, 사람마다 쓰러뜨림·쓰러짐·준 피해, 🏅 MVP(쓰러뜨림이 가장 많은 사람, 같으면 준 피해가 많은 사람).
  - 방장: **⚔ 한 판 더** 또는 **🎯 연습으로**. 다른 사람은 방장이 고를 때까지 기다림.
- 점수 계산: 쓰러진 사람이 "쓰러뜨린 사람의 팀 +1"을 서버에 올림. 시간은 서버 시계 기준이라 모두 같게 끝남.
