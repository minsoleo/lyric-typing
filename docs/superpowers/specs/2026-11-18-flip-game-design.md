# 판 뒤집기 (팀전 타자게임) 설계

## 왜 만드나
- 민솔님이 학교 정보 시간에 친구들과 **각자 컴퓨터로** 같이 하는 팀전 타자게임을 원함.
- 친구들이 **장문(긴 문장)** 으로도 하고 싶어 해서, 방 설정에서 짧은 단어 / 긴 문장을 고를 수 있어야 함.
- 이 게임 다음에는 "스킬 이름을 쳐서 쓰는 2D 대전 게임"을 만들 예정 → 이번에 붙이는 연결(Firebase)을 그때 다시 씀.

## 목표
- 4자리 방 코드로 친구들이 모여 빨강 vs 파랑 팀으로 판 뒤집기를 할 수 있다.
- 학교 컴퓨터(정보실)와 노트북에서 돌아간다.
- 친구들은 가입 없이 닉네임만으로 들어온다.

## 하지 않는 것
- 초성 게임 (나중에)
- 노래 가사로 판 만들기 (저작권: 가사는 각자 브라우저에만 저장하기로 했음)
- 순위표, 기록 저장, 로그인
- 채팅

## 실패로 보는 것 (돌아가도 안 되는 것)
- 친구 화면에 뒤집힌 카드가 늦게(1초 넘게) 보이거나 화면마다 판이 다르게 보임
- 노트북 화면에서 판과 입력 칸이 한 화면에 안 들어옴
- 방장이 아닌 사람이 규칙을 몰라 헤맴

## 제약
- 사이트는 GitHub Pages(정적 파일)라서 서버 코드를 둘 수 없음.
- 연결은 Firebase Realtime Database (무료 Spark 요금제).
  - 주소: `https://lyric-typing-6ead1-default-rtdb.asia-southeast1.firebasedatabase.app` (싱가포르)
  - 보안 규칙 (2026-11-18 게시, 동작 확인함): `rooms/<숫자 4자리>` 아래만 읽기/쓰기 가능, 그 밖은 모두 막힘.
  - SDK 앱 등록(apiKey) 없이 databaseURL만으로 연결.
- 학교 인터넷이 Firebase를 막는지는 아직 모름 → 학교에서 확인 필요.

## 방법 검토
| 방법 | 장점 | 단점 | 결과 |
|---|---|---|---|
| Firebase Realtime Database | 학교에서 될 가능성 높음(일반 https), 튼튼함, 2D 게임에 재사용 | 처음 가입 필요 | **선택** (민솔님 결정) |
| 공개 중계 서버 / 방장 컴퓨터 직접 연결(WebRTC) | 가입 없음 | 학교 인터넷에서 막힐 가능성 큼, 불안정 | 제외 |
| 한 컴퓨터에서 번갈아 | 준비 없음 | 동시에 못 쳐서 판 뒤집기 재미가 사라짐 | 제외 |

## 민솔님이 정한 것
- 판 크기: 짧은 단어, 긴 문장 **둘 다 7x7 (49장)**
- 연결: Firebase
- 방 설정에서 짧은 단어 / 긴 문장 선택

## 제가 정한 것 (바꿀 수 있음)
- 새 페이지 `flip.html` (타자연습 `index.html`과 분리), 홈에 "판 뒤집기" 버튼으로 연결
- 4자리 방 코드, 방장이 방 만들기, 대기실에서 각자 팀 선택 + 방장 "팀 섞기"
- 시간: 60 / 90 / 120초 (기본 90)
- 긴 문장은 10~18자 (7x7 카드 안에서 읽을 수 있는 길이)
- 단어·문장 목록은 직접 만든 것 (짧은 단어 150개, 긴 문장 100개)에서 매판 49개를 섞어 뽑음
- 카드는 처음에 모두 주인 없음, 카드 글과 똑같이 치고 Enter → 우리 팀 색, 상대 카드도 뺏을 수 있음
- 끝나면 카드 많은 팀 승리, 가장 많이 뒤집은 사람(MVP) 표시, "한 판 더"(같은 팀 그대로)
- 한 방 최대 16명
- 끝난 방은 정리(오래된 방은 다음 방 만들 때 지움)
- 밝은/어두운 버전, 글꼴, 색은 타자연습 사이트와 같게

## 만드는 사람에게 맡기는 것
- 동시에 같은 카드를 뒤집을 때의 처리 (Firebase transaction으로 마지막 사람 기준)
- 시간 맞추기 (Firebase 서버 시간 기준으로 끝나는 시각 저장)
- 방장이 나갔을 때 다음 사람에게 방장 넘기기
