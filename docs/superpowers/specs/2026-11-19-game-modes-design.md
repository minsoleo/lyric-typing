# 숲속의 한바탕 — 대결 모드 3가지 (킬내기전 · 깃발쟁 · 점령전) 설계

## 왜 만드나
- 지금 "⚔ 대결"은 상대를 많이 쓰러뜨리는 방식 하나뿐이에요. 민솔님이 **게임을 다양하게** 하고 싶어서 모드를 3가지로 늘려요.
- 친구들(최대 8명, 빨강/파랑 팀)과 온라인 방에서 함께 해요.

## 민솔님이 정한 것

### 킬내기전
- 지금 있는 대결과 똑같아요. 제한 시간(2/3/5분) 동안 상대를 많이 쓰러뜨린 팀이 이겨요.
- **맵은 지금 숲 맵 그대로** 써요 (3200x1800, 좌우 대칭).

### 깃발쟁
- 맵 한가운데에 깃발이 하나 있어요. 깃발을 집으면 그 사람의 팀이 1초마다 점수를 얻어요.
- 깃발을 든 사람이 쓰러지면 깃발이 그 자리에 떨어져요. **같은 팀을 포함해 누구나** 다시 주울 수 있어요.
- 깃발이 바닥에 떨어져 있는 동안에는 어느 팀도 점수를 얻지 못해요.
- 제한 시간이 끝났을 때 점수가 더 많은 팀이 이겨요.
- 1초에 얻는 점수는 시간이 갈수록 커져요: 1점 → 2점 → 3점. 각 구간의 길이는 **3 : 2 : 1**이에요.
  - 3분이면: 처음 1분 30초는 1점, 다음 1분은 2점, 마지막 30초는 3점
  - 2분이면: 1분 / 40초 / 20초 · 5분이면: 2분 30초 / 1분 40초 / 50초
- 맵은 **넓은 새 맵**을 써요.

### 점령전
- 점령 구역이 3개 있어요. 빨강 팀 출발 자리 근처에 하나, 맵 한가운데에 하나, 파랑 팀 출발 자리 근처에 하나예요.
- **1턴 (점령하기)**: 구역 안에 서 있어야 게이지가 차요. 1명이면 0→100%가 **40초**, 사람이 많을수록 빨라요 (2명 20초, 3명 약 13초). 100%가 되면 "점령 완료"이고 구역이 그 팀 색으로 바뀌어요.
- **2턴 (완전 점령)**: 점령 완료한 구역은 **아무도 없어도** 1명이 서 있는 속도(40초에 100%)로 저절로 차요. 우리 팀이 그 구역에 서 있으면 서 있는 사람 수만큼 더 빨라요 (2명이 서 있으면 3명분 속도). 100%가 되면 "완전 점령"이고, 그 구역은 더 이상 뺏을 수 없어요.
- **전쟁 중**: 두 팀이 한 구역 안에 같이 있으면 사람 수와 상관없이 "⚔ 전쟁 중"이 뜨고 그 구역의 게이지가 모두 멈춰요.
- **뺏기**: 완전 점령이 되기 전에 상대 팀이 그 구역에서 자기 1턴 게이지를 100% 채우면, 구역이 상대 팀 색으로 바뀌어요.
- **게이지는 팀마다 따로 남아요 (0으로 돌아가지 않음)**: 예) 빨강이 2턴 60%일 때 파랑이 뺏으면, 파랑의 2턴은 0%부터 시작하고 빨강의 60%는 그대로 남아요. 나중에 빨강이 다시 뺏으면 60%부터 이어서 차요.
- **승리**: 구역 **2곳을 먼저 완전 점령한 팀**이 그 자리에서 이겨요.
- **제한 시간 없음.** 판이 끝나지 않는 경우(예: 1곳씩 완전 점령 + 마지막 구역에서 계속 전쟁 중)에도 **끝내기 버튼 없이 계속** (민솔님 결정). 한 팀이 모두 나가면 남은 팀이 이김.
- 맵은 깃발쟁과 같은 **넓은 새 맵**을 써요.

## 민솔님이 반대하지 않아서 제 제안대로 정한 것
- 상대 팀 **혼자만** 우리 구역(점령 완료, 2턴 진행 중)에 서 있으면: 우리 팀의 2턴 게이지는 **멈추고**, 그동안 상대의 1턴(뺏기) 게이지가 차요.
- 다시 살아나는 시간은 지금처럼 **3초**, 자기 팀 출발 자리에서.
- 깃발을 든 사람은 **느려지지 않아요**. 대신 **작은 지도에 모두에게 보이고, 그림자 은신을 써도 깃발은 보여요.**

## 목표
- 방장이 방에서 모드(킬내기전/깃발쟁/점령전)를 고르고 대결을 시작할 수 있어요.
- 깃발 위치·누가 들었는지·점령 게이지가 **모든 친구 화면에 똑같이** 보여요.
- 지금 킬내기전은 지금과 똑같이 돌아가요.
- 노트북(1366x650)에서도 스크롤 없이 한 화면.

## 하지 않는 것
- 깃발쟁·점령전용 새 그림 (깃발·점령 구역은 우선 코드로 그림. 나중에 지피티 그림으로 바꿀 수 있음)
- 모드별로 다른 넓은 맵 2개 (넓은 맵 하나를 같이 씀. 해 보고 필요하면 나중에 나눔)
- 깃발을 든 사람 느려짐, 깃발이 저절로 가운데로 돌아가기
- 혼자 연습에서 깃발쟁·점령전 규칙 돌리기 (혼자서는 맵 구경만)

## 실패로 보는 것
- 친구마다 깃발이 다른 사람 손에 있거나, 게이지 %가 다르게 보임
- 방장이 나가면 깃발·점령 상태가 사라지거나 처음으로 돌아감
- 점령전에서 이겼는데 판이 안 끝남 / 깃발쟁에서 시간이 끝났는데 판이 안 끝남
- 새 맵에서 출발 자리·점령 구역·깃발 자리가 나무나 바위에 막힘

## 방법 (Approaches)
1. **(고름) 넓은 새 맵 하나를 깃발쟁·점령전이 같이 쓰고, 깃발·점령 계산은 방장 컴퓨터가 함.**
   - 지금 허수아비와 같은 방식이에요: 방장이 모두의 위치(0.1초마다 받는 상태)를 보고 계산해서, 결과를 1초에 5번 서버에 올리면 모두가 그걸 그려요. 방장이 나가면 다음 방장이 서버에 남은 상태에서 이어서 계산해요.
   - 장점: 모두에게 똑같이 보임, 지금 구조를 그대로 씀.
2. 각자 컴퓨터가 깃발·게이지를 따로 계산 → 친구마다 결과가 달라질 수 있어서 뺌.
3. 모드마다 맵을 따로 2개 → 일이 두 배라서 뺌 (나중에 필요하면).

민솔님은 "만드는 방법"을 맡겨 주셔서 1번을 제가 골랐어요.

## 만드는 방법 (자세히)

### 맵을 여러 개로 바꿀 수 있게
- 새 파일 **`magic-maps.js`**: 맵마다 `{id, name, W, H, left(왼쪽 절반 나무·바위), center(가운데 것), path(흙길), spawn{red, blue, solo}, dummies(허수아비 자리), decorSeed, flag(깃발 자리), zones(점령 구역 3개)}`.
  - `forest`: 지금 숲 맵 (지금 값을 그대로 옮김)
  - `wide`: 넓은 새 맵
- `magic.js`의 `WW, WH, OBSTACLES, WALLS, BLOCKERS, DECOR, PATH, SPAWN`을 "지금 맵" 기준으로 다시 만드는 `setMap(id)`로 바꿈. 작은 지도 그림(`mmBg`)도 맵이 바뀌면 다시 만듦. 허수아비도 그 맵 자리로.
- 맵 고르는 규칙: 킬내기전 → `forest`, 깃발쟁·점령전 → `wide`.

### 넓은 새 맵 (`wide`)
- 크기 **4800x2400** (지금의 1.5배 x 1.33배). 화면(1600x900)은 그대로, 작은 지도 비율만 맞춤.
- **좌우 대칭** (지금처럼 왼쪽 절반만 적으면 오른쪽은 거울). 숨을 곳은 적게, 맵 전체에 고르게 (민솔님이 앞서 원한 방향).
- 빨강 출발 왼쪽 끝 가운데, 파랑 출발 오른쪽 끝 가운데.
- 깃발 자리 = 맵 정가운데. 점령 구역: 가운데(2400, 1200) + 양쪽 출발 자리에서 조금 앞 (예: x 1200 / 3600). 구역은 반지름 약 200의 원.
- 깃발 자리·구역 안·출발 자리 주변에는 나무·바위·연못을 두지 않음. 흙길은 출발 자리 → 구역 → 가운데 → 구역 → 출발 자리로 이어짐.
- 지금 있는 그림(풀밭·흙길·나무·바위·연못·장식)을 그대로 씀.

### 방에서 모드 고르기
- 방에 `gmode`('kill' | 'flag' | 'zone')를 둠. 방장만 바꿀 수 있고, 바뀌면 **연습 중에도 모두의 맵이 바로 바뀜** (모두 자기 팀 출발 자리로).
- 방 막대의 "⚔ 대결 시작" 옆에 모드 고르기 칸. 시간 고르기(2/3/5분)는 킬내기전·깃발쟁에서만 보이고 점령전에서는 숨김.
- 연습 중(대결 전) 넓은 맵에는 깃발과 점령 구역이 **흐리게 보이기만** 하고 규칙은 안 돌아감 ("대결을 시작하면 켜져요").
- 혼자 연습에서도 맵을 고를 수 있게 작은 버튼 (숲 맵 / 넓은 맵) — 구경용.

### 깃발 · 점령 상태 (방장이 계산)
- 서버 `rooms/<코드>/obj` (방장만 씀, 1초에 5번):
  - 깃발쟁: `{flag: {x, y, by(든 사람 pid 또는 없음)}, score: {red, blue}}`
  - 점령전: `{zones: [{own(주인 팀 또는 없음), c: {red, blue}(1턴 게이지 0~100), h: {red, blue}(2턴 게이지 0~100), war(전쟁 중), lock(완전 점령)}…3개]}`
- 대결 시작 때 방장이 `obj`를 처음 상태로 씀. 판이 끝나거나 연습으로 돌아가면 지움.
- 방장이 바뀌면 새 방장이 서버에 있는 `obj`를 읽어서 이어서 계산.

### 깃발쟁 규칙 계산 (방장)
- 깃발이 바닥에 있고, 살아 있는 사람이 깃발에서 **60** 안에 들어오면 그 사람이 집음 (여러 명이면 가장 가까운 사람).
- 든 사람이 쓰러지거나(상태의 `dead`) 방에서 나가면 그 사람의 마지막 위치에 깃발이 떨어짐.
- 깃발을 든 동안 그 팀 점수 += (지금 구간의 점수) x 지난 시간. 구간은 대결 시간의 처음 3/6 = 1점, 다음 2/6 = 2점, 마지막 1/6 = 3점.
- 시간이 끝나면 점수가 많은 팀 승리 (같으면 무승부). 화면에는 점수를 정수로 보여 줌.
- 깃발은 든 사람 머리 위에 그림 (은신 중이어도 깃발은 보임). 작은 지도에 깃발 위치 표시.

### 점령전 규칙 계산 (방장, 구역마다 매 순간)
- `n빨강`, `n파랑` = 구역 안에 있는 **살아 있는** 사람 수. 속도 1명분 = 100/40 (%/초).
- 완전 점령(`lock`)이면 아무것도 안 바뀜.
- 두 팀 다 있으면 → `war = true`, 아무 게이지도 안 바뀜.
- 한 팀(T)만 있을 때:
  - T가 주인이면 → T의 2턴 게이지 `h[T]` += (1 + n_T)명분.
  - T가 주인이 아니면 → T의 1턴 게이지 `c[T]` += n_T명분 (주인 팀의 2턴은 멈춤). `c[T]`가 100이 되면 주인 = T. 이때 **진 팀의 1턴 게이지는 0으로** (다시 뺏으려면 다시 채워야 하니까), **진 팀의 2턴 게이지는 그대로 남음**.
- 아무도 없고 주인이 있으면 → 주인의 2턴 게이지 += 1명분 (저절로).
- 주인 팀의 `h`가 100이 되면 `lock = true` (완전 점령).
- 끝나지 않은 1턴 게이지는 사람이 나가도 줄어들지 않고 남음.
- **(제 결정)** 아무 주인도 없는 구역을 한 팀이 먼저 100% 채우면, 상대 팀이 채우던 1턴 게이지도 0으로 (뺏길 때와 같은 규칙. 예: 빨강 90%에서 파랑이 먼저 100% → 빨강 0%). 바로 되뺏기는 걸 막음.
- **(제 결정)** 그림자 은신 중인 사람도 구역 안 사람으로 셈 → 상대가 숨어서 들어오면 "⚔ 전쟁 중"이 떠서 "누가 있다!"는 걸 알 수 있음 (몸은 계속 안 보임).
- **(제 결정)** 한 팀이 방에서 모두 나가면, 남은 팀이 그 자리에서 이김 (깃발쟁·킬내기전도 같음).
- 한 팀이 완전 점령 2곳이 되면 그 자리에서 승리 → 방장이 `match`에 `winner`와 끝난 시간을 씀.
- 화면: 구역 원(주인 팀 색, 없으면 흰색), 원 둘레에 게이지 고리, "⚔ 전쟁 중" 글씨, 완전 점령은 굵은 테두리 + 🔒. 위쪽 점수판 자리에 구역 3개(왼쪽·가운데·오른쪽)의 상태. 작은 지도에도 구역 색.

### 대결 진행 (지금 구조를 넓힘)
- `match`에 `mode`를 추가. 점령전은 `endAt`이 없고(제한 시간 없음) 방장이 승리를 쓰면 끝남.
- 결과 화면: 킬내기전은 지금처럼, 깃발쟁은 팀 점수, 점령전은 "구역 2곳 완전 점령!" + 이긴 팀. 개인 기록표(쓰러뜨림·쓰러짐·준 피해)와 MVP는 모든 모드에 그대로.
- 대결 시작 3·2·1 안내 문구를 모드에 맞게 ("깃발을 오래 들고 있으면 이겨요" / "구역 2곳을 먼저 완전 점령하면 이겨요").

### 계산은 테스트
- 깃발 점수 구간(`flagRate(지난 시간, 전체 시간)`), 깃발 줍기, 점령 한 순간 계산(`zoneStep`), 승리 판정을 `magic-logic.js`에 넣고 `tests/magic-logic.test.html`에 테스트 추가.
