# 숲속의 한바탕 — 팀마다 같은 화면 + 성 맵(점령전) + 동양풍 맵(깃발쟁) 설계

## 왜 만드나
- 지금은 빨강 팀은 왼쪽(또는 왼쪽 위)에서, 파랑 팀은 오른쪽에서 출발해요. 그래서 **팀에 따라 화면이 달라 보여요.**
- 민솔님은 **브롤스타즈처럼 어느 팀이든 내 화면에서는 똑같이 보이기**를 원해요. 우리 팀은 항상 같은 자리에서 출발하고, 상대는 항상 반대쪽에 있어요.
- 이게 있어야 점령전의 높이 차이가 말이 돼요. "출발 → 계단 올라 A → 계단 올라 B"가 **두 팀 모두 올라가는 느낌**이어야 하거든요. 지금처럼 빨강이 왼쪽 위에서 시작하면 B로 갈 때 화면 아래로 내려가는 느낌이 들어요.
- 맵의 분위기도 바꿔요. 점령전은 **성**, 깃발쟁은 **동양풍**이에요.

## 목표
1. **팀마다 같은 화면**: 킬내기전 · 깃발쟁 · 점령전 세 맵 모두.
2. **점령전 성 맵**: 지금보다 크게, 민솔님이 그린 모양, 계단으로 오르내리는 높이 차이.
3. **깃발쟁 동양풍 맵**: 크기는 지금 넓은 맵과 같게(4800×2400), 높이 차이 없음.

## 하지 않는 것
- 높이에 따른 **사거리·피해 차이는 없어요** (민솔님 결정). 높이는 다니는 길만 바꿔요.
- 진짜 3D나 2층 다리(밑으로 지나가기)는 만들지 않아요.
- 낭떠러지에서 뛰어내리기는 없어요. **오르내리기는 계단에서만** 해요.

## 실패로 보는 것
- 한 팀만 유리한 지형 (두 팀 화면이 조금이라도 다르면 실패)
- 친구 화면에서 내 위치·공격·효과가 엉뚱한 곳에 보이기
- 글씨나 캐릭터가 거꾸로 보이기

## 1. 팀마다 같은 화면

### 민솔님이 정한 것
- 빨강이든 파랑이든 **내 화면에서는 우리 팀이 같은 자리에서 출발**해요.

### 어떻게 보이나
- **숲 맵(킬내기전) · 동양풍 맵(깃발쟁)**: 좌우 대칭이라서, 파랑 팀은 좌우만 뒤집어서 봐요. 두 팀 모두 **왼쪽에서 출발**하고 상대는 오른쪽이에요.
- **성 맵(점령전)**: 180도 돌려도 같은 모양이라서, 파랑 팀은 180도 돌려서 봐요. 두 팀 모두 **왼쪽 아래에서 출발**하고 상대는 오른쪽 위예요.
- 혼자 연습할 때는 지금처럼 빨강 쪽에서 출발해요.

### 만드는 방법 (내가 정한 것)
- 파랑 팀 컴퓨터는 게임 안의 모든 위치를 **"내 화면 좌표"**로 다뤄요. 맵이 대칭이라서 맵 자체(나무·벽·구역)는 그대로 쓰고, 나는 빨강 출발 자리에서 시작해요.
- 친구와 위치를 주고받을 때만 바꿔요. 보낼 때는 내 화면 좌표를 원래 좌표로 바꾸고, 받을 때는 원래 좌표를 내 화면 좌표로 바꿔요.
  - 좌우 뒤집기: x → 맵 폭 − x
  - 180도 돌리기: x → 맵 폭 − x, y → 맵 높이 − y
  - 방향도 같이 바꿔요 (날아가는 공격의 방향, 바라보는 방향, 휘두르는 각도).
- 바꿔야 하는 것: 내 상태(위치·바라보는 방향), 신호(날아가는 공격, 효과, 바위벽, 장판, 성역, 생명의 샘, 맞기와 끌어당기는 자리), 허수아비 위치, 깃발 위치.
  - 점령 구역은 번호로 주고받아요. 번호는 원래 좌표 기준이고, 화면에 그릴 때만 내 화면 자리를 써요.
- 이 방법을 고른 이유: 캐릭터 그림과 글씨가 똑바로 선 채로 맵만 돌아가요. 화면 전체를 뒤집으면 글씨·캐릭터가 거꾸로 서서, 그리는 곳 수십 군데를 하나하나 다시 돌려야 해요.
- 바꾸는 계산은 `magic-logic.js`에 함수로 두고 신호 종류마다 테스트해요.
- 팀을 바꾸면(팀 ⇄) 내 화면 기준도 바로 바뀌고 출발 자리로 돌아가요.
- 점령 구역 이름은 화면 기준으로 보여요: **우리 쪽 / 가운데 / 상대 쪽**. 점수판의 구역 3칸도 내 화면 순서(우리 쪽이 왼쪽)로 그려요.

## 2. 점령전 성 맵

### 민솔님이 정한 것
- 모양은 민솔님이 그린 그림대로예요: 출발 자리가 대각선 구석에 있고, 가운데로 꺾인 넓은 복도가 이어져요.
- 지금 넓은 맵보다 **크게** 만들어요.
- 컨셉은 **성**이에요.
- 높이 차이는 **계단에서만** 있어요. 출발 → A(또는 C) 사이에 계단, A(또는 C) → B 사이에 계단.
- **B 구역(싸움이 가장 많이 일어나는 곳)은 평평하게** 해요.
- 높이에 따른 사거리·피해 차이는 없어요.

### 모양 (내 화면 기준, 두 팀 똑같음)
■ = 성벽, 숫자 = 층

```
 ■ ■ ■ ■ ■ ■ ■ ■ 1 1 1 상대 출발
 ■ ■ 2 2 2 3 3 2 2 Ⓒ2 1
 2 2 2 3 Ⓑ3 3 3 2 2 2 2
 1 Ⓐ2 2 3 3 3 2 2 ■ ■ ■
 내 출발 1 ■ ■ ■ ■ ■ ■ ■ ■ ■
```
- 1층: 출발 자리. 2층: 우리 쪽 구역 Ⓐ, 상대 쪽 구역 Ⓒ. 3층: 가운데 구역 Ⓑ.
- **Ⓑ는 3층** (2026-11-21 민솔님 확정: "3층으로 하자"). 출발 1층 → 계단 → Ⓐ 2층 → 계단 → Ⓑ 3층, 한 팀에 계단 2개.
- **Ⓑ 둘레는 넓고 평평한 3층 광장**이에요. 광장 안에는 계단이나 낭떠러지가 없어요. (내가 이해한 것: "B는 평평하게" = B 둘레에서는 층이 바뀌지 않음)
- 한 칸 위 층은 **낭떠러지(성벽)로 둘러싸여 있고**, 계단으로만 오르내려요.
- 낭떠러지는 **걷기·돌진·끌려오기만 막아요.** 공격(날아가는 것, 근접, 범위)은 그대로 넘어가요. 지금 연못과 같은 방식이에요.

### 크기·자리 (내가 정한 것, 해 보고 조정)
- 맵 크기 **6400 × 3800** (지금 넓은 맵 4800 × 2400). 출발 자리에서 상대 출발 자리까지 걸어서 약 30초.
- 맵은 180도 돌리면 정확히 같아요. 맵 데이터는 절반만 적고 나머지는 게임이 돌려서 만들어요.
- 계단: 출발 → Ⓐ 하나, Ⓐ → Ⓑ 하나 (상대 쪽도 똑같이). 계단 폭은 캐릭터 3~4명이 나란히 지나갈 정도.
- 숨을 곳: 성 기둥·석상·상자 같은 작은 장애물을 조금만, 골고루. Ⓑ 광장에도 몇 개.
- 허수아비 3개(연습용): Ⓐ·Ⓑ·Ⓒ 근처.

### 높이가 눈에 보이게
- 높은 층의 아래쪽 가장자리에 **성벽 면**(돌벽)을 그려서 높아 보이게 해요. 화면을 돌려 봐도 항상 화면 아래쪽에 벽 면이 보여요.
- 층마다 바닥 밝기를 조금 다르게 해요 (높을수록 밝게).
- 계단은 계단 그림, 작은 지도에도 층 색과 계단이 보여요.

### 성 그림 (지피티에게 부탁, 문장은 내가 써 줌)
- 돌바닥 타일, 성벽 면(이어 붙는 타일), 계단, 망루·기둥, 팀 깃발(빨강·파랑), 횃불, 작은 장애물(석상·상자·통).
- 그림이 오기 전에는 코드로 그린 임시 성으로 먼저 놀 수 있게 해요.

## 3. 깃발쟁 동양풍 맵

### 민솔님이 정한 것
- 크기는 지금 넓은 맵과 **같아요** (4800 × 2400).
- 컨셉은 **동양풍**이에요.
- 높이 차이는 없어요.

- **느낌 (민솔님이 보여 준 사진, 2026-11-20)**: 안개 낀 산속의 동양 사원·궁궐. 진한 회색 기와지붕에 금색 테두리, 붉은 기둥·들보, 회색 돌바닥 마당(주황 줄무늬), 회색 바위 절벽, 분홍·주황 꽃나무.
- **깃발은 빨간색 느낌**으로 (금색 테두리의 붉은 깃발).

### 내가 정한 것 (바꿔도 돼요)
- 배치(나무·바위·연못 자리, 길, 깃발 자리, 출발 자리)는 **지금 넓은 맵 그대로** 쓰고 그림만 바꿔요. 이미 막힘 없이 확인한 배치라서요.
- 바꾸는 그림:
  - 땅 → 안개 낀 푸른빛 이끼 풀밭, 흙길 → 회색 돌바닥 길(주황 줄무늬)
  - 나무 → 분홍 꽃나무 · 주황 단풍나무 · 소나무, 바위 → 회색 바위 기둥(사진 속 절벽 같은)
  - 연못 → 연꽃 연못 + 붉은 아치 다리
  - 장식 → 석등 · 대나무 · 꽃잎 더미 · 회양목
  - 가운데 깃발 자리 → 둥근 돌 제단(밟고 지나갈 수 있음, 장식만)
- **깃발이 빨간색이라 빨강 팀과 헷갈릴 수 있어서**: 바닥에 있을 때도, 누가 들고 있을 때도 깃발은 늘 같은 붉은 깃발이에요. 들고 있는 팀은 **깃발 끝 리본과 발밑 고리를 팀 색**으로 그려서 구분해요.
- 이것도 지피티 그림을 받고, 오기 전에는 지금 숲 그림을 그대로 써요.

### 지피티 그림 목록 (파일 이름)
- 동양풍: `art/east-ground.webp`(풀밭 타일) · `east-path.webp`(돌길 타일) · `east-props.webp`(나무 3 + 바위 기둥 3) · `east-pond.webp`(연못 + 다리) · `east-decor.webp`(장식 3×3) · `east-flag.webp`(붉은 깃발 + 돌 제단)
- 성: `art/castle-floor.webp`(돌바닥 타일) · `castle-wall.webp`(성벽 면 띠) · `castle-stairs.webp`(계단 2) · `castle-props.webp`(장애물 3×2) · `castle-banners.webp`(빨강·파랑 깃발 + 성문)

## 만드는 순서
1. **팀마다 같은 화면** (지금 숲 맵·넓은 맵에서 먼저 완성하고 확인)
2. **성 맵** (모양·계단·낭떠러지·임시 그림) → 지피티 그림이 오면 바꿔 끼우기
3. **동양풍 맵** (그림만 바꾸기, 지피티 그림이 오면)

## 만드는 사람에게 남긴 것
- 성 맵의 정확한 좌표, 계단 위치, 작은 장애물 자리 (위 모양과 크기를 지키는 안에서)
- 임시 성 그림의 모양과 색
- 신호마다 어떤 칸이 위치·방향인지는 코드를 보고 빠짐없이 찾기 (테스트로 확인)
