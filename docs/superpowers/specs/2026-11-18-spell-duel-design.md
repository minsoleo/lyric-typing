# 주문 대결 (타자 마법 2D 게임) 설계 — 1단계: 혼자 연습판

## 왜 만드나
- 민솔님이 친구들과 1대1·팀전으로 하는 2D 게임을 원함. 판 뒤집기처럼 "단순히 빨리 치기"가 아니라, **스킬 이름을 쳐야 스킬이 나가는** 게임.
- 타자가 빠르고 정확할수록 게임도 잘하게 되는 것이 핵심 재미.

## 전체 계획 (단계)
1. **혼자 연습판** (이 문서): 허수아비 상대로 이동·평타·주문이 재밌는지 다듬기. 인터넷 연결 없음 → 학교에서도 무조건 됨.
2. 1대1 온라인 (Firebase, 판 뒤집기처럼 4자리 방 코드)
3. 팀전 (2대2, 3대3)

## 민솔님이 정한 것
- **탑뷰** (위에서 내려다보는 맵)
- **마우스 왼쪽 클릭 = 이동** (클릭한 곳으로 걸어감), **오른쪽 클릭 = 평타**
- **키보드는 스킬 이름만** 침 (WASD 없음 → 한글 자판과 안 겹침)
- **마법 컨셉**

## 목표 (1단계)
- 연습판에서 클릭 이동, 평타, 주문 7개를 써서 허수아비를 쓰러뜨릴 수 있다.
- 스킬 이름을 치는 동안에도 캐릭터는 마지막으로 클릭한 곳으로 계속 걸어간다.
- 노트북(1366x650)에서 스크롤 없이 한 화면.

## 하지 않는 것 (1단계)
- 온라인 대결, 팀, 방 코드, 채팅
- 소리, 그림 파일(캐릭터·효과는 도형과 색으로 그림)
- 레벨·경험치·상점

## 실패로 보는 것
- 한글 주문을 치는데 글자가 빠지거나, 조립 중인 글자 때문에 맞게 쳤는데 실패로 나옴
- 오른쪽 클릭 때 브라우저 메뉴가 뜸
- 주문을 치다가 클릭하면 입력이 날아감

## 방법
- 브라우저 기본 **캔버스**로 그림 (게임 엔진 같은 큰 도구 없이) → 학교 컴퓨터에서도 가벼움. (Phaser 같은 게임 엔진은 크고, 이 정도 게임엔 필요 없어서 제외)
- 새 페이지 `magic.html` + `magic.js`(화면·조작) + `magic-logic.js`(계산, 테스트 `tests/magic-logic.test.html`)
- 밝은/어두운 버전은 타자연습과 같은 설정 공유

## 제가 정한 것 (바꿀 수 있음)
- 게임 이름: **주문 대결**
- 맵: 넓은 마법 정원 (나무·바위가 이동과 마법을 막음)
- 체력 100, 허수아비도 체력 100 → 쓰러지면 3초 뒤 다시 일어남
- **오른쪽 클릭 평타**: 마우스 쪽으로 작은 마법 구슬, 피해 8, 0.6초마다
- **주문**: 아무 때나 키보드로 치면 화면 아래 주문 칸과 **내 머리 위**에 보임 → Enter로 **마우스가 가리키는 쪽**으로 발사. 이름이 정확히 맞아야 나감. 틀리면 "주문 실패!" + 0.8초 동안 다시 못 씀. Esc는 지우기.
- 주문 7개 (긴 이름일수록 강함, 쓰고 나면 잠깐 못 씀 = 재사용 대기시간):

| 주문 | 글자 | 효과 | 재사용 |
|---|---|---|---|
| 불꽃 | 2 | 불덩이 발사, 피해 12 | 1.5초 |
| 얼음 감옥 | 4 | 맞으면 1.5초 얼어붙음, 피해 6 | 6초 |
| 순간 이동 | 4 | 마우스 위치로 이동 (최대 거리 있음) | 8초 |
| 마법 방패 | 4 | 3초 동안 피해 30까지 막음 | 10초 |
| 치유의 빛 | 4 | 체력 25 회복 | 12초 |
| 바람의 칼날 | 5 | 뚫고 지나가는 칼날, 피해 18 | 4초 |
| 하늘을 가르는 천둥 번개 | 11 | 0.7초 뒤 마우스 위치에 번개, 넓은 범위 피해 45 | 15초 |

- 화면 옆에 **주문책**(주문 이름·효과·남은 대기시간)을 보여 줌 → 이름을 몰라서 못 쓰는 일 없게
- 허수아비 모드: 가만히 서 있기 / 좌우로 움직이기 (움직이는 과녁 연습)

## 만드는 사람에게 맡기는 것
- 장애물에 부딪혔을 때 미끄러지는 방식
- 피해 숫자가 떠오르는 효과, 마법 색깔과 모양
- 2단계 온라인을 위해 "게임 상태"와 "그리기"를 나눠 두기
