# 팀마다 같은 화면 (Team View) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 파랑 팀은 맵을 뒤집어 보게 해서, 빨강·파랑 누구나 내 화면에서는 왼쪽(같은 자리)에서 출발하게 한다.

**Architecture:** 각 컴퓨터는 "내 화면 좌표(local)"로만 게임을 돌린다. 맵을 불러올 때 내 팀의 view(`null` | `'x'` | `'xy'`)로 맵의 모든 자리를 뒤집고, 친구와 주고받는 위치·방향만 경계에서 뒤집는다(뒤집기는 두 번 하면 원래대로라서 보낼 때·받을 때 같은 함수). 원래 좌표(canonical) = 빨강 팀·혼자 연습 화면.

**Tech Stack:** 순수 JS (magic.js, magic-logic.js, magic-maps.js), Firebase Realtime DB, 테스트 `tests/magic-logic.test.html`(브라우저에서 열어 #sum 확인).

**Spec:** `docs/superpowers/specs/2026-11-20-team-view-and-new-maps-design.md` (1번 "팀마다 같은 화면"만. 성 맵·동양풍 맵은 다음 계획)

## Global Constraints
- 숲 맵·넓은 맵: 파랑 팀은 **좌우 뒤집기**(`sym: 'x'`): x → W − x. 성 맵(다음 계획)은 `'xy'`: x → W − x, y → H − y.
- 빨강 팀·혼자 연습은 뒤집지 않음 (view = null).
- 글씨·캐릭터 그림은 거꾸로 서면 안 됨 (화면 전체를 뒤집지 말고 좌표만 뒤집기).
- 게임 파일을 올릴 때마다 magic.html·flip.html의 `v=` 판 번호를 바꿈 (지금 20261120c → 다음 20261120d).
- 구역 이름: 화면(점수판·구역 글씨)에는 **우리 쪽 / 가운데 / 상대 쪽**, 모두에게 같은 글로 가는 소식에는 **빨강 쪽 / 가운데 / 파랑 쪽**. 혼자 연습 화면은 빨강 쪽 / 가운데 / 파랑 쪽.

## Review Focus
1. 연습 중 팀 바꾸기(팀 ⇄): 이미 있던 친구·허수아비·깃발이 새 화면 기준 자리로 바로 옮겨져야 함 (0.1초 동안 엉뚱한 곳으로 미끄러지면 안 됨).
2. 파랑 팀 사람이 방장이 될 때(방장 넘김): 깃발 위치·점령 게이지·허수아비가 그대로 이어져야 함.
3. 대결 중 들어온 사람(파랑): 깃발이 맞는 자리에, 구역 이름이 자기 기준으로 보여야 함.
4. 강철 사슬로 끌어당기기·바위벽·레이브 궁극기 범위·생명의 샘·성역: 상대 팀 화면에서도 같은 땅 위에 보여야 함.
5. 방향이 있는 것(날아가는 공격, 휘두르기 각도, 바라보는 방향): 상대 화면에서 반대로 보이면 안 됨.

### Task 1: 뒤집기 계산 (magic-logic.js)

**Files:**
- Modify: `magic-logic.js` (MagicLogic에 추가)
- Test: `tests/magic-logic.test.html`

**Interfaces:**
- Produces:
  - `viewOf(team: string, sym: 'x'|'xy'|null) -> 'x'|'xy'|null` — team이 'blue'일 때만 sym.
  - `flipPt(p:{x,y}, view, W, H) -> {x,y}` (새 객체, view null이면 복사본)
  - `flipVec(v:{x,y}, view) -> {x,y}`, `flipAng(a: number, view) -> number` ('x': π − a, 'xy': a + π)
  - `flipRect(o:{x,y,w,h,...}, view, W, H) -> 새 객체` ('x': x → W − x − w, 'xy': y → H − y − h도)
  - `flipEvent(ev, view, W, H) -> 새 신호` — 바꾸는 것: `fx`(v.x, v.y, v.a), `shot`(s.x, s.y, s.vx, s.vy), `wall`(pts[]), `field`/`zone`/`sanc`(x, y), `hit`(pl{x,y}). 나머지 신호·칸은 그대로. view null이면 ev 그대로.
  - `flipState(st, view, W, H)` — x, y, fa[ x, y ]
  - `flipDummies(arr, view, W, H)` — 각 배열의 [0], [1]
  - `flipObj(o, view, W, H)` — o.flag가 있으면 flag.x, flag.y (나머지 그대로, o null이면 null)
  - `zoneLabel(side: 'red'|'mid'|'blue', team) -> string` — team이 red/blue면 '우리 쪽'/'가운데'/'상대 쪽', 아니면 '빨강 쪽'/'가운데'/'파랑 쪽'
- 모든 함수는 입력을 바꾸지 않는다.
