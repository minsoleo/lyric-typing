# 판 뒤집기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 친구들이 각자 컴퓨터에서 4자리 방 코드로 모여 빨강 vs 파랑 팀으로 7x7 판 뒤집기 타자게임을 한다.

**Architecture:** 정적 페이지 `flip.html` + 순수 로직 `flip-logic.js` + 단어 목록 `flip-words.js` + 화면/연결 `flip.js`. 방 상태는 Firebase Realtime Database `rooms/<code>` 한 곳에 두고 모든 화면이 그 값을 구독해 그린다. 카드 뒤집기는 카드 하나 단위 transaction.

**Tech Stack:** HTML/CSS/바닐라 JS, Firebase JS SDK 10.12.2 compat (gstatic CDN, app + database), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-18-flip-game-design.md`

## Global Constraints
- databaseURL: `https://lyric-typing-6ead1-default-rtdb.asia-southeast1.firebasedatabase.app` (apiKey 없이 이것만으로 initializeApp)
- 쓰기 가능 경로는 `rooms/<숫자 4자리>` 아래뿐 (그 밖은 Permission denied)
- 판 7x7 = 49장, 짧은 단어 모드와 긴 문장 모드 모두
- 시간 60/90/120초, 기본 90
- 한 방 최대 16명
- 긴 문장 10~18자, 목록: 짧은 단어 150개, 긴 문장 100개 (직접 지은 것, 가사 금지)
- 테마: localStorage `lyricTyping.theme` ('light'|'dark')를 타자연습과 공유, 색 토큰 동일
- 노트북 1366x650에서 점수줄 + 판 + 입력 칸이 스크롤 없이 한 화면

## Review Focus
- 두 사람이 같은 카드를 거의 동시에 뒤집음 → 카드는 한 팀 색으로 일관되게 보이고, flips는 실제로 뒤집은 사람만 +1 (Task 4: transaction 결과로만 flips 증가)
- 방장이 창을 닫음 → 남은 사람 중 가장 먼저 들어온 사람이 방장이 됨 (Task 1 `nextHost` 테스트)
- 이미 우리 팀 카드인 글을 침 → 아무 일 없고 "이미 우리 팀 카드" 안내 (Task 1 `findTarget` 테스트)
- 공백·NFC 차이(붙여넣기 금지 상태에서 한글 조합형 등) → 같은 글로 인정 (Task 1 `norm` 테스트)
- 게임 중 새로 들어온 사람 → 인원이 적은 팀에 배정되어 바로 참여 (Task 1 `smallerTeam` 테스트)

### Task 1: 순수 로직 + 테스트 페이지

**Files:** Create `flip-logic.js`, `tests/flip-logic.test.html`

**Interfaces — Produces (`window.FlipLogic`):**
- `norm(s: string): string` — NFC, 연속 공백 1칸, 앞뒤 공백 제거
- `pickCards(pool: string[], n: number, rand: () => number): string[]` — 중복 없는 n개
- `findTarget(cards: {t,o}[], typed: string, team: 'red'|'blue'): {index: number, reason: 'flip'|'own'|'none'}`
- `prefixHits(cards, typed): number[]` — norm(typed)로 시작하는 카드 번호 (typed 비면 [])
- `tally(cards): {red: number, blue: number, none: number}`
- `mvp(players: {[pid]: {name, flips}}): {pid, name, flips} | null` — flips 0이면 null
- `balanceTeams(pids: string[], rand): {[pid]: 'red'|'blue'}` — 인원 차 최대 1
- `smallerTeam(players): 'red'|'blue'` — 같으면 'red'
- `nextHost(players: {[pid]: {joinedAt}}): string | null` — joinedAt 가장 작은 pid
- `makeCode(rand): string` — '0000'~'9999' 4자리

- [ ] Step 1: 테스트 페이지에 위 함수별 assert 작성 (norm('  가  나 ')==='가 나', findTarget 3가지 reason, tally 합 49, balanceTeams 5명 → 3/2, nextHost 최소 joinedAt, pickCards 길이·중복 없음)
- [ ] Step 2: 브라우저에서 열어 FAIL 확인
- [ ] Step 3: `flip-logic.js` 구현
- [ ] Step 4: 모든 줄 PASS 확인

### Task 3: 페이지 뼈대 + 방 만들기/들어가기/대기실

**Files:** Create `flip.html`, `flip.js`
**Consumes:** FlipLogic, FLIP_WORDS
**방 데이터:** `rooms/<code> = {createdAt, host, state: 'lobby'|'playing'|'ended', round, settings: {mode: 'word'|'sentence', seconds}, players: {<pid>: {name, team, joinedAt, flips}}, cards: [{t, o: ''|'red'|'blue', by}], startsAt, endsAt}`
- 방 만들기: makeCode → transaction(비었거나 createdAt 6시간 지난 방만 차지)
- 들어가기: 방 없음/16명 꽉 참 안내, 팀은 smallerTeam
- players/<pid> onDisconnect().remove(), 방장 없으면 nextHost가 스스로 host 기록
- 대기실: 팀 두 칸, 팀 바꾸기 버튼, 방장만 설정(모드·시간)·팀 섞기·시작
- [ ] 창 2개로 방 만들기 → 들어가기 → 팀 이동 → 방장 나가면 넘어감 확인 → Commit

### Task 4: 게임 판

- 시작: cards = pickCards 49, startsAt = 서버시각+3초, endsAt = startsAt + seconds
- 서버 시각: `.info/serverTimeOffset`
- 7x7 그리드, 카드 색(없음/빨강/파랑), 입력 중 prefixHits 강조, 3·2·1 카운트다운
- Enter: findTarget → 'flip'이면 cards/i transaction(state playing && 시간 안 && o !== team) → 성공 시 players/<pid>/flips increment(1); 'own'/'none'은 안내
- 시간 끝: 방장이 state='ended' (transaction, round 일치)
